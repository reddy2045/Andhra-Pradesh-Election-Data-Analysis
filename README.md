# Andhra Pradesh Election Data Analysis

## Project Overview
Analyzed Andhra Pradesh Election 2024 dataset using Python and Pandas to identify voting patterns, winning candidates, and party-wise performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Analysis
- Data Cleaning
- Missing Value Handling
- Party-wise Analysis
- Candidate-wise Analysis
- Winner Analysis
- Data Visualization

## Files
- AP_Election_Data_Analysis.ipynb
- AP_Election_Data.csv
- AP_Election_Data.xlsx
